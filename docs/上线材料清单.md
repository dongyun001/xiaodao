## 二、危机词表与应急话术【必填】

### 2.1 危机关键词审阅 ☐

系统对"自杀、自残"等危机表述会立即返回固定救助话术并通知辅导员，判断依据是一份关键词表。系统已内置一份默认词表（自杀/自残/轻生/跳楼/割腕等常见表述），需要：

- 请**心理中心老师**审阅默认词表，补充遗漏的表述、删掉不适合的词。
- 提供**误报词**：哪些词出现在正常语境里不该触发告警（例如课程名、歌词、引用句式等）。

## 五、钉钉告警群机器人【必填】

学生出现危机情况时，系统往一个钉钉群发告警。需要：

1. 建一个（或指定一个已有的）告警接收群，群成员为应接收告警的辅导员。☐
2. 在群里添加**自定义机器人**：群设置 → 智能群助手 → 添加机器人 → 自定义，安全设置选择**「加签」**。☐
3. 把机器人的 **Webhook 地址**和**加签密钥（SECRET）**私聊交给开发。☐

## 六、AI 服务账号【必填】

系统需要两个 AI 服务账号：一个用于生成回答，一个用于文本向量化（向量化服务二选一）：

- **DeepSeek（生成回答用）**【必填】：到 platform.deepseek.com 注册并充值，创建 **API Key** 私聊交付。（金额不大，具体额度咨询开发对接人）
- **文本向量化服务**【必填，二选一】：
  - 方案 A：SiliconFlow 平台注册一个 API Key（有免费额度，最简单）；
  - 方案 B：学校有 GPU 服务器的话可本地部署，需要信息中心提供一台机器——把服务器情况告诉开发评估。

## 交付与安全要求

1. **凭据类材料（四、五、六、八的密码密钥）不要发到任何群里**，当面交付或一对一私聊；收到后建议尽快在对应平台改一次密。
2. 文档类材料（一、二、三、七、九）打包命名：`上线材料-类别-日期`，例如 `上线材料-规章制度-20261025.zip`。
3. 分批交付时，请在本清单上勾选已交付项，随材料一并发回，便于双方对账。
4. 所有材料里**不要包含学生个人信息**（名单、聊天记录等）；如制度文件里含个人身份信息页，请先删去。
