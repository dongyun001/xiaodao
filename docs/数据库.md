# 数据库

> 表结构以 Alembic 迁移为准，本文件是说明。首次迁移 `bee02ce1c501` 建立三张表；改结构必须先改契约与本文档，再新增迁移。

## 迁移

```bash
alembic upgrade head      # 建表、vector 扩展、HNSW 索引
alembic downgrade -1      # 回滚一步
alembic revision --autogenerate -m "add xxx"
```

- 连接串只来自环境变量（`app/config.py`），`alembic.ini` 里的 `sqlalchemy.url` 留空。
- `CREATE EXTENSION IF NOT EXISTS vector;` 已包含在初始迁移里；回滚不删除扩展。
- 禁止用 `Base.metadata.create_all()` 或自动 ddl 建表。
- 向量维度在迁移里写死 `1024`，模型侧读 `Settings.VECTOR_DIMENSION`。**换 embedding 模型必须新建迁移**，重建 `embedding` 列与 HNSW 索引，不能只改环境变量。

## knowledge_base（知识库条款）

一条记录只含一条条款，`id` 由 `doc_num`（缺省用文件 slug）+ `chapter` + `article_num` 稳定生成，重复入库按 `id` upsert。

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | `varchar(255)` PK | 稳定 id |
| `doc_num` | `integer` | 文档编号，可空 |
| `doc_title` | `varchar(255)` NOT NULL | 文档标题 |
| `category` | `varchar(64)` NOT NULL | 板块分类 |
| `source_url` | `varchar(1024)` | 来源链接 |
| `version` | `varchar(64)` | 文档版本 |
| `effective_date` | `date` | 生效日期 |
| `status` | `varchar(32)` | 现行/废止 |
| `chapter` | `varchar(255)` | 章 |
| `section` | `varchar(255)` | 节，可空 |
| `article_num` | `varchar(64)` NOT NULL | 条号 |
| `article_title` | `varchar(255)` | 条标题，可为空 |
| `content` | `text` NOT NULL | 条款原文 |
| `embedding` | `vector(1024)` NOT NULL | embedding 文本 = `doc_title + chapter + article_title + content` |
| `created_at` / `updated_at` | `timestamptz` NOT NULL | 默认 `now()` |

索引：`ix_knowledge_base_article_num`、`ix_knowledge_base_category`、`ix_knowledge_base_embedding_hnsw`（HNSW + `vector_cosine_ops`）。

## official_notice（官网通知）

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | `integer` PK | 自增 |
| `title` | `varchar(512)` NOT NULL | 通知标题 |
| `url` | `varchar(1024)` NOT NULL | 原文链接 |
| `published_at` | `timestamptz` | 站点显示的发布时间，北京时间换算成 UTC |
| `content` | `text` NOT NULL | 通知正文（纯文本，已剔除内嵌 `<style>`） |
| `content_hash` | `varchar(64)` NOT NULL | 正文去空白后的 SHA-256，唯一 |
| `embedding` | `vector(1024)` NOT NULL | embedding 文本 = `标题 + 正文` |
| `fetched_at` | `timestamptz` NOT NULL | 采集时间，默认 `now()` |
| `created_at` | `timestamptz` NOT NULL | 默认 `now()` |

索引：`uq_official_notice_content_hash`（唯一）、`ix_official_notice_published_at`、`ix_official_notice_embedding_hnsw`。

去重按 `content_hash`，重复采集不新增记录。

## qa_log（问答审计日志）

**只允许 INSERT 和只读查询**：没有 UPDATE/DELETE 接口、后台按钮或 ORM 写方法。

| 列 | 类型 | 说明 |
|---|---|---|
| `id` | `integer` PK | 自增 |
| `question` | `text` NOT NULL | 学生原话；仅授权人员可查，列表与日志脱敏 |
| `path` | `varchar(32)` NOT NULL | 取值见 `docs/接口契约.md` §1.1 |
| `intent` | `varchar(32)` | 意图 |
| `emotion` | `varchar(32)` | 情绪 |
| `urgency` | `varchar(16)` | 紧急度 |
| `need_type` | `varchar(32)` | 需求类型 |
| `openid` | `varchar(64)` | 仅用于告警去重与追溯；展示时掩码或哈希 |
| `retrieved_clauses` | `jsonb` | 命中条款 |
| `top_similarity` | `double precision` | top1 相似度 |
| `generated_answer` | `text` | 生成内容 |
| `is_high_risk` | `boolean` NOT NULL | 危机为 `true` |
| `sensitive_words_hit` | `jsonb` | 命中词 |
| `filter_result` | `varchar(16)` NOT NULL | 默认 `pass` |
| `alert_sent` | `boolean` NOT NULL | 仅发送成功后为 `true`，被去重抑制保持 `false` |
| `created_at` | `timestamptz` NOT NULL | 默认 `now()` |

索引：`ix_qa_log_created_at`、`ix_qa_log_openid`、`ix_qa_log_path`。
